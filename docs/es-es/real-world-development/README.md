Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar pull requests y gestionar el trabajo con agentes.

## Situación

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está registrado como incidencias de GitHub, listas para que elijas una. Incluye trabajo de funcionalidad, como el filtrado y la paginación, además de mejoras de calidad, como la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot te acompaña allá donde trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza la situación compartida de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades de agente, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación de GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo de sesión, colabora en canvas y gestiona incidencias y pull requests de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las pull requests que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
